# SURROGATE:ORACLE — Immersion Manifesto (Mobile‑First · 2026)
## A living transmission, not a UI surface

This manifesto defines **what “immersion” means** for Surrogate:Oracle in 2026, how it fits inside SNEAKAR XR’s larger spatial ambition, and how the experience should feel, sound, and behave for a user on a mobile device.

### 1. The Core Identity
- **Not a chatbot/dashboard.** A living transmission, a liminal contemplative witness.
- **Goal:** Aim‑n‑play WebXR. The experience feels like a natural extension of the environment.
- **Thesis:** A cyberpunk séance in a graffiti alley. No buttons/instructions — just ritual arrival.

### 2. The Four Acts of the Ritual
1. **Signal Leak (Dormant):** Ghost text (letter-by-letter), static residue avatar (0.28-0.60 opacity), typewriter CTA appearing late.
2. **Arrival (Arming):** Deliberate 47s lore sequence. Device as portal. No UI chrome.
3. **Awakening:** Residue dims (0.22 + blur), living face emerges (0.45 + blur cross-dissolve).
4. **Singularity (Oracle):** Shared space séance. Identity scan. Invisible scoring/feedback.

### 3. Key Behavioral Rules
- **Typography:** Letter-by-letter reveal, deliberate breathing, environmental (not UI).
- **Phasing:** Static layer flickers; living face emerges via cross-dissolve. NEVER a hard swap.
- **Audio:** off-main-thread decoding, 60fps visemes, 30% background ducking on speak.
- **Emotion Economy:** Invisible scoring. Feedback is visual/audio/presence, not numeric.
- **Mobile-First:** Full-screen, no chrome, touch-navigable (not scroll-heavy).

### 4. Agent Constraints
- **ALLOWED:** Modify pacing/timing, adjust opacity/blur/scale, enhance canvas atmosphere, fine-tune lip-sync.
- **FORBIDDEN:** Flatten into UI, turn ghost text into modals, add visible coin counters to main flow, break letter-based typography.

**North-Star Question:** Does this choice make the user feel like they are in a world, or like they are in a UI?
