# Unified Presence Permission Architecture (v2)

## Core Insight: Permission = Bearer Token

Browser permission grants persist for the **entire SPA session** after a single `getUserMedia` call. The actual `MediaStream` tracks can be stopped and re-acquired freely — the grant is the token, not the stream.

```
Splash Tap (one gesture)
   └── getUserMedia({ video + audio })  →  ONE combined dialog
   └── DeviceOrientation.requestPermission()  →  piggybacked (iOS)
          │
          ├── video tracks → kept live for AR / face tracking
          └── audio tracks → stopped immediately (not needed yet)
                                 │
                      [... user plays SNEAKARCADE games ...]
                                 │
                            Oracle mic-tap later
                            └── getUserMedia({ audio })
                                 → INSTANT (permission already granted)
                                 → ZERO prompt
```

**One permission moment. Zero re-prompts. Entire session.**

## Problem (Current State)

Three independent acquisition sites, up to 3 native permission dialogs:

| Site | What it acquires | When | Problem |
|---|---|---|---|
| `HolodeXRShell.bootUnifiedSession` (line 594) | Camera + gyro | Splash tap | Only gets camera, not mic |
| `SurrogateOracleImmersion.onMicClick` (line 1906) | Camera + mic ("joint warmer") | Oracle mic-tap | Acquires → immediately stops → re-acquires. iOS hates this. |
| `OracleConversation.startMic` (line 780) | Audio only | Mic button | Third `getUserMedia` call, third potential prompt |

Additionally, `useParallax` and `useXRMode` both independently call `requestDeviceOrientationPermission()` with **no deduplication** — can trigger double iOS motion dialogs.

### 1. Shared Presence Preflight Module

#### [NEW] [`lib/presence/startPresencePreflight.ts`](file:///c:/Users/User/Documents/Anti-Gravity/PROJECTS/KREAIT-PRO/sneakar-xr-engine/lib/presence/startPresencePreflight.ts)

Single entry point. Acquires **all three capabilities** in one gesture. Singleton-deduped.

```typescript
export interface PresenceResult {
  stream: MediaStream | null;     // combined video + audio
  motionGranted: boolean;
  error?: string;
}

// Singleton — concurrent calls share the same in-flight request
let activeRequest: Promise<PresenceResult> | null = null;
let cachedResult: PresenceResult | null = null;

export async function startPresencePreflight(): Promise<PresenceResult> {
  if (cachedResult?.stream?.active) return cachedResult;
  if (activeRequest) return activeRequest;
  activeRequest = acquire();
  cachedResult = await activeRequest;
  activeRequest = null;
  return cachedResult;
}

async function acquire(): Promise<PresenceResult> {
  let motionGranted = true;
  let stream: MediaStream | null = null;

  // Parallel: motion permission + getUserMedia
  const [motionResult, mediaResult] = await Promise.allSettled([
    requestDeviceOrientationPermission('[Preflight]'),
    navigator.mediaDevices.getUserMedia({
      video: { facingMode: 'user', width: { ideal: 1280 }, height: { ideal: 1280 } },
      audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true, channelCount: 1 },
    }),
  ]);

  if (motionResult.status === 'fulfilled') motionGranted = motionResult.value;
  if (mediaResult.status === 'fulfilled') stream = mediaResult.value;

  return { stream, motionGranted, error: mediaResult.status === 'rejected' ? String(mediaResult.reason) : undefined };
}

/** Extract just the video tracks as a new stream (for camera/face subsystems). */
export function extractVideoStream(combined: MediaStream): MediaStream {
  return new MediaStream(combined.getVideoTracks());
}

/** Stop audio tracks but keep video alive. Permission grant persists. */
export function releaseAudioTracks(combined: MediaStream): void {
  combined.getAudioTracks().forEach(t => t.stop());
}
```

const activateCameraWithStream = useCallback((combinedStream: MediaStream) => {
  const videoTracks = combinedStream.getVideoTracks();
  if (!videoTracks.length) {
    console.warn('[XR] activateCameraWithStream: no video tracks in stream');

  // Stop any existing camera stream first
