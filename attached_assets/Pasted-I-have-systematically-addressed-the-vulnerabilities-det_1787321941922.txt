I have systematically addressed the vulnerabilities detailed in the adversarial leak council report while preserving the
  existing user experience:

  1. Critical IDOR & Capability Bindings (Seeker Echo, Portrait Gallery, Claim Links, Culture Coins)
   - Removed reliance on client-supplied seekerKey and UUIDs.
   - Identity is now derived securely server-side from cf-connecting-ip.
   - Ownership verification is strictly enforced across seeker-echo, portrait-gallery, generate-claim-link, and
     culture-coin-manager. Callers can only interact with rows mapped to their IP address (or the wallet address registered to
     their IP via user_wallets).

  2. Gemini Live Proxy & Client IP Exfiltration
   - Moved the ORACLE_SYSTEM_PROMPT and all hidden scoring logic out of the client bundle and into
     supabase/functions/gemini-live-proxy/promptBlocks.ts. 
   - gemini-live-proxy now securely enforces the Gemini native audio model and constructs the systemInstruction server-side,
     preventing arbitrary proxy usage and shielding the Oracle IP from DevTools inspection.

  3. Persistent Transcript Storage
   - Removed the raw unauthenticated conversation_turns REST calls from the React codebase. 
   - The client no longer syncs raw transcripts directly to Supabase REST, relying solely on the compact summaries persisted
     safely by the server edge functions.

  4. Portrait Generation Leaks
   - Stripped raw seekerLines and sensitive email payloads from the gemini-portrait-generator context block.
   - Removed internal promptUsed, error details, and provider logic from the generator's JSON response, ensuring only safe,
     opaque portrait statuses and URLs reach the frontend.
   - Hardened the promptLeaksSeekerLines function by dropping seekerLines altogether.

  5. Wildcard PostMessage Origins
   - Replaced the unsafe * target origins in useWalletBridge.ts and useXRMode.ts with explicit window.location.origin bindings
     to prevent malicious cross-origin frame hijacking.

  6. Development Secrets & Logging
   - Trace Credential: Erased the shared ORACLE_TRACE_DEV_TOKEN from .env.local and refactored oracle-trace/index.ts to require
     a Supabase JWT (checking for authorized sneakar.io operators).
   - PII: Removed the email values and OTP tokens from console.log statements in useAuth.ts and GoogleSignInOverlay.tsx.
   - Public Dev Log: Restrained the /api/oracle-log relay within vite.config.ts so it actively rejects requests in production
     (NODE_ENV === 'production'), enforces explicit host origin checks, and places a strict length limit on the body.
   - Crash UI: Sanitized main.tsx to stop displaying raw error traces to production users during crashes.
